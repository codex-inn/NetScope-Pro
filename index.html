Start in three steps

The Windows build is packaged as a downloadable executable artifact.

Download

Open the Windows executable workflow, choose the latest successful run, then download the NetScopePro-Windows ZIP under Artifacts.

Open build downloads ↗

Extract & launch

Extract the ZIP and run NetScopePro.exe. The local app opens a browser dashboard on your own computer. Install Nmap separately for Nmap scans.

Check & export

Sign in using your local configuration, run the desired check, then download JSON or use Print / Save PDF for a report.

Important: the public page is a project homepage, not a remote scanner.
Browsers and static hosting cannot safely inspect your computer's Wi-Fi or run local network scans from a hosted page. For those features, use the local Windows app. This page does not collect scan data or credentials.

Understand the result labels

Verified

A specific technical check passed, such as valid TLS or successful DNS resolution. It is not a guarantee that a link is safe.

Unverified / Suspicious

There is insufficient evidence or a caution indicator needs review. Check the destination independently before trusting it.

Failed

A particular check failed or the target could not be reached. It does not automatically mean the target is malicious.

RepositoryAutomated testsSecurity notes

NetScope Pro is an MVP for authorized testing, not a certified security product. Only scan systems you own or have explicit permission to assess.
