Network Tools

What a website can—and cannot—check without a local agent or backend.

🌐

Public DNS

Available: query A, AAAA, MX, NS, TXT, CAA, and other public DNS record types for a hostname.

🔎

URL risk signals

Available: parse URL, identify HTTP, punycode, user-info, unusual ports, IP literal, and known shortener domains.

📶

Local Wi-Fi scan

Not available in a normal hosted browser: websites cannot read your Wi-Fi SSID, saved network details, router, or nearby devices.

🖧

LAN port scanning

Not available here: browser sandboxing and network security rules prevent reliable scanning of private IPs and ports.

🛡️

Live site security headers

Limited: cross-origin browser rules prevent dependable inspection of arbitrary sites' response headers or TLS certificate details.

🧾

On-screen reports

Available: copy findings to clipboard or use your browser's Print / Save PDF feature. History stays in local browser storage.

Accuracy note: DNS success or HTTPS in the URL does not prove a site is trustworthy. This web-only version does not claim to detect malware, scan Wi-Fi, or certify links as safe.
